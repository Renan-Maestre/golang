# Resumo

Nessa seção, aprendemos diversos conceitos importantes enquanto criamos uma **API CRUD** completa para o nosso dicionário.

CRUD representa as quatro operações básicas:

- **Create** — Criar
- **Read** — Ler
- **Update** — Atualizar
- **Delete** — Deletar
